# Гайдлайн интерфейса Antresol

Правила вида панели, сняты с кода 0.1.0 (22.10.2026). Общие правила семьи — `Anvil/docs/STYLE.md` и
`Anvil/docs/MOTION.md`; здесь — то, что своё у панели. Новое правило — сюда в том же шаге, что и код.
Порядок, если источники расходятся: решение владельца → этот гайдлайн → код.

## 1. Характер

Полоса-полка у края экрана: зашёл, щёлкнул, ушёл. Всё видно сразу, без вложенных окон.

- **Одна строка карточек** под шапкой; каждая карточка — модуль. Доля ширины — `Module::weight`
  (Экран 1,8, остальные 1).
- **Шапка 40**: знак и «Antresol» слева; справа налево — закрыть, настройки (на их месте — «назад»),
  закрепить. Закреплено — значок на мягкой подложке акцента.
- **Настройки** — вместо карточек, в той же панели, двумя карточками; не отдельным окном.
- **Никаких всплывающих списков** (ComboBox, меню): окно равно панели, всплывающее обрежется. Выбор из
  многих — список строк в карточке, из немногих — `segmented`, не влезает — листается вбок.

## 2. Окно и размеры

| Что | Значение | Где |
|---|---|---|
| Размер по умолчанию | 1100 × 300 | `config::Settings::default` |
| Ширина | 560 … ширина монитора | `MIN_WIDTH` |
| Высота | 150 … 520 | `MIN_HEIGHT`, `MAX_HEIGHT` |
| Нижние углы | радиус 14 (регион окна), верхние — прямые | `app::CORNER` |
| Ручки размера | 7 по краям, 16 в углах; чёрточка 36 × 3 посередине низа | `app::GRIP`, `grips` |
| Отступы панели | 12 по бокам, 6 сверху, 14 снизу | `draw` |
| Зазор между карточками | 10 | `cards` |

Фон панели — `surface` с рамкой `border`; карточки — `card_frame` набора. Теней нет (окно непрозрачное).

## 3. Цвета, текст, элементы

- Только `anvil_ui::Palette`; акцент — `Accent::BLUE` (свой не заведён).
- Заголовок карточки — `section_label`; подписи групп внутри — тоже `section_label`.
- Строка списка (разрешение, устройство) — `modules::row`: 28 высотой, текст 13,5 (выбранная — `text`,
  иначе `weak`), пометка справа 12 `faint`; длинное — с многоточием.
- Свои кнопки — `Kind::Secondary` со значком; «Править кнопки» — `Kind::Ghost`.
- Значок динамика — свой (в наборе нет): волны по громкости, без звука — крестик цветом `danger`.
- Ошибки — уведомлением набора (`Toasts`) с `Tone::Danger`; подтверждение режима — баннер `Warning`
  с «Оставить» (главная) и «Вернуть».

## 4. Движение

- Выезд окна — `motion::ENTER` (240 мс, `ease_out`), уход — `LEAVE` (120 мс); «Показывать анимацию»
  в Windows выключено — мгновенно.
- Карточки и строки списков входят по очереди (`Motion::enter`, шаг `STAGGER`).
- Громкость в цифрах — плавно (`Motion::value`, `HOVER`); чёрточка ручки — плавно к акценту под мышью.

## 5. Языки и проверка

Строки — `texts.rs` (RU/EN), строки набора — `anvil_ui::tr`. Единицы тоже переводятся («Гц»/«Hz»).
Проверка: снимки панели в обеих темах и на обоих языках (`config.txt`: `lang=`, `theme=`), только
вырезка панели.

## Известные отклонения

- Значок программы — временно знак набора `Icon::Layers`.
- Подсказки (`on_hover_text`) у нижнего края панели могут обрезаться окном.
