## Что это и что уже работает

Панель быстрого доступа у верхнего края монитора (только Windows). Прячется за край, выезжает,
когда мышь упирается в край напротив панели, или по горячей клавише. Внутри три модуля:

- **Экран** — разрешение, частота, масштаб выбранного монитора;
- **Звук** — громкость, «без звука», устройство вывода;
- **Кнопки** — свои кнопки из файла: программа, папка, файл или адрес.

Не сделано: значок программы, выбор горячей клавиши, порядок и выключение модулей, остальные идеи
из [SPEC.md](../SPEC.md).
