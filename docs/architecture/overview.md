# Как устроено

Один исполняемый файл `antresol.exe`, eframe/egui с набором `anvil-ui` (тег `kit-v0.6.1`).

| Файл | Что |
|---|---|
| `src/main.rs` | окно: без рамки, поверх всех, без кнопки на панели задач |
| `src/app.rs` | окно-панель: место у края, выезд, шапка, карточки модулей, настройки, ручки размера |
| `src/panel.rs` | логика «показана / спрятана» без окна (тесты) |
| `src/modules/` | модули: `display.rs`, `audio.rs`, `buttons.rs`; общий `Module` в `mod.rs` |
| `src/sys/` | Windows: `monitor.rs` (мониторы, курсор, полноэкранное), `display.rs` (режимы, масштаб), `audio.rs` (Core Audio), `mod.rs` (запуск, горячая клавиша, автозапуск, скругление окна) |
| `src/config.rs` | `config.txt` и `buttons.txt` |
| `src/texts.rs` | строки RU/EN |

## Окно

Окно и есть панель: того же размера, по центру верхнего края монитора. Выезд — окно само
съезжает из-за края вниз (`ENTER` 240 мс, уход `LEAVE` 120 мс по шкале Anvil); выключена анимация
в Windows — мгновенно. Нижние углы — регион окна (`SetWindowRgn`). Спрятанное окно стоит правее
всех мониторов. Почему не прозрачное окно: прозрачность OpenGL на части систем рисуется белым, а
«пропускать мышь» (`WS_EX_LAYERED`) белит всё окно.

Мышь у края узнаётся по положению курсора на экране (`GetCursorPos`) 25 раз в секунду, пока
панель спрятана; это дёшево. Горячая клавиша — `RegisterHotKey` в своём потоке.

## Системные вызовы

- Режимы экрана — `EnumDisplaySettingsW` / `ChangeDisplaySettingsExW` (с записью в реестр).
- Масштаб — `DisplayConfigGetDeviceInfo` / `SetDeviceInfo` с недокументированными пакетами −3/−4:
  масштаб задаётся шагом от рекомендованного по шкале 100…500 %.
- Звук — `IMMDeviceEnumerator`, `IAudioEndpointVolume`; основное устройство — недокументированный
  `IPolicyConfig` (как панель звука Windows).
- Автозапуск — строка `Antresol` в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.

## Как добавить модуль

1. Файл в `src/modules/`, структура с `impl Module`: `key`, `title`, `refresh` (перечитать систему —
   при выезде и раз в 1,5 с), `ui` (карточка), по желанию `weight` (доля ширины), `busy` (не прятать
   панель), `ticking` (нужны кадры).
2. Строка в `modules::all()`; строки — в `texts.rs` на двух языках; системное — в `src/sys/`.
3. Вид — по [гайдлайну](../ui-guideline.md); страницу [usage](../guide/usage.md) дополнить.
