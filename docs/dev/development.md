# Как разрабатывать

Нужны Rust (1.98) и Windows. Только диск E:.

```bash
cargo build -j 4
python E:/dev_personal/tools/checks.py --repo . -j 4 fmt test clippy
```

Тесты — логика показа/скрытия (`panel.rs`), разбор файлов (`config.rs`), выбор режима и масштаба
(`modules/display.rs`, `sys/display.rs`), цвета и их контраст, свой цвет, HSV (`look.rs`), протокол Kamerton (`sys/kamerton.rs`), ночной свет (`sys/nightlight.rs`), живое чтение Wi‑Fi, VPN, плана, темы (`sys/net.rs`, `--ignored`), картинка из буфера и живое распознавание
текста, нарисованного в памяти (`sys/ocr.rs`, `--ignored`), закреплённые тексты и часы в файле (`config.rs`), самая горячая зона (`sys/res.rs`), разница поясов и живые пояса (`sys/tz.rs`, `--ignored`), сдвиг мониторов для основного (`sys/display.rs`), наполнение полоски
(`panel.rs`), профили и сочетания клавиш (`config.rs`, `modules/display.rs`),
коды клавиш (`sys/mod.rs`), входы DDC/CI (`sys/ddc.rs`), имя программы и мониторы (`sys/monitor.rs`), PNG
снимка (`shot.rs`), ключ трека (`modules/media.rs`), ресурсы (`sys/res.rs` — в том числе настоящий замер этого ПК), история буфера и закрепление
(`modules/clipboard.rs`), лоток (`modules/tray.rs`), полки: разбор, запись, переход со старого `modules=`, операции
(`config.rs`), что каждый модуль стоит на готовой полке (`modules/mod.rs`), правка полок без окна — перетаскивание, клавиши,
переименование, вуаль над модулями (мышь, колесо, клавиатура), ряд в правке и «Ещё N ›», шапка на узких панелях
(`app.rs`, модуль `tests`), заслон писателей в Windows, выдуманный экран и откат «Оставить?» без окна (`sys/mod.rs`,
`sys/display.rs`, `modules/display.rs`), HDR: биты ответа Windows, отказы, выдуманный монитор (`sys/display.rs`), кнопка,
профили с HDR и их откат, ширина карточки (`modules/display.rs`), щелчок по кнопке «HDR» без окна, в том числе под вуалью
правки (`app.rs`), слова `hdr` / `sdr` в `profile=` (`config.rs`),
адреса Bluetooth и настоящий опрос (`sys/bt.rs`),
таймеры и «помидор» (`modules/timers.rs`), разбор ответов GitHub и время (`sys/gh.rs`,
`modules/github.rs`). Сеть — отдельно: `cargo test -- --ignored` читает открытый репозиторий панели.

## Живая проверка

- `target\debug\antresol.exe` — в debug видна консоль с журналом (по-английски).
- `ANTRESOL_TRACE=1` — печатать каждую смену места или размера окна (доля выезда, место, размер, тема) и
  что ответили мониторы по DDC/CI.
- `ANTRESOL_DEMO=1` — выдуманный мир: монитор (4K, свои режимы, масштаб и HDR — вначале выключен), звук Kamerton, часы (от 10:00 UTC, свой
  пояс — UTC), яркость и входы, трек, ресурсы, диски и программа на переднем плане (`player.exe`): снимки для
  открытого репозитория (`docs/img`) — только так, на демо-настройках (папка `antresol-scratch\demo`).
  **Правило демо: клавиш профилей нет, монитор несуществующий (`\\.\DISPLAY9`), в Windows ничего не пишется** (заслон
  `sys::blocked`; настоящее только читается; профили демо-настроек — без клавиш и на `\\.\DISPLAY9`; тесты идут в том
  же выдуманном мире, см. «Как устроено»).
- `ANTRESOL_VIEW=settings` — открыть сразу настройки (для снимков без щелчков), `color` — «Свой цвет…»,
  `edit` — правка полок, `strip-media` — панель спрятана, у края полоска с медиа (`media_strip` включается только на
  этот запуск), `strip-banner` — плашка «Таймер дошёл»; `ANTRESOL_SHELF=2` — сразу открыть вторую полку (с 1);
  `ANTRESOL_PIN=1` — панель закреплена с запуска и не уезжает (снимать через 3 с, когда выезд точно закончился).
- Своя папка настроек для проверки — `APPDATA=E:\dev_personal\antresol-scratch\appdata` (задавать через
  PowerShell `$env:APPDATA`, из Git Bash путь не доходит); пока запущена панель владельца, собирать копию в
  `CARGO_TARGET_DIR=E:\dev_personal\antresol-scratch\target-test`.
- `ANTRESOL_SHOT=файл.png` — панель через 4 с снимает своё окно (egui, только само окно — чужой экран в
  кадр не попадёт) и закрывается (сам закрепляет панель; нет снимка за 20 с — закрывается без него); для
  `docs/img` — только так, вместе с `ANTRESOL_DEMO=1`. Монитор уснул — окно не рисуется и снимка не будет.
- Все снимки `docs/img` разом — `powershell -File scripts\shots.ps1` (собранная копия в `target-shot`, свои
  выдуманные настройки в `antresol-scratch\appdata-shot`, четырнадцать сцен: три полки, правка полок, настройки, свой
  цвет — в тёмной теме на русском и в светлой на английском, полоска с медиа и плашка).
- Снимок `ANTRESOL_SHOT` — без сжатия (мегабайты); в `docs/img` — только через
  `powershell -NoProfile -File scripts\squeeze-png.ps1 -In снимок.png -Out docs\img\имя.png` (без потерь, ~100 КБ).
- Снимки захватом экрана — только для своей проверки после запуска (панель видна 2 с). Курсор не двигать: за ПК может
  работать владелец. В `docs/img` класть только вырезку самой панели.
- Не нажимать в проверках смену режима экрана, HDR, основного монитора, ночного света, темы, уведомлений, Wi‑Fi, VPN, плана питания, масштаба, яркости и автозапуск без команды
  владельца — это его настройки. Окно для проверки запускать только с `ANTRESOL_DEMO=1` (и своей папкой настроек): так
  оно этих настроек не касается.

## CI на GitHub

- `.github/workflows/ci.yml` — одна система, `windows-latest`: `cargo fmt --check`, `cargo clippy --locked --all-targets
  --all-features -- -D warnings`, `cargo test --locked --all-features --no-fail-fast`, `cargo build --release --locked`;
  собранный `antresol.exe` — артефакт запуска на 14 дней. Rust — `1.98.1`, как на ПК (поднимать вместе с ПК).
- Запуск — кнопкой (Actions → CI → Run workflow, или `ghci.py run` из скилла `github-ci`) и сам на тег выпуска `v*`;
  на пуш в ветку не запускается. Репозиторий открытый — минуты не считаются; кнопку нажимают после новой версии и перед
  выпуском, по решению владельца. Новый запуск отменяет идущий, потолок — 60 минут.
- Перед кнопкой — те же команды с теми же флагами на ПК (`CARGO_TARGET_DIR` на E:). Тесты в CI идут в выдуманном мире,
  как и на ПК: в Windows раннера ничего не пишется.
