Антресоль — анимация значка (петля 3 с; в программе — один раз по событию)

A · Выезд

Панель выезжает из-за кромки экрана и уезжает обратно. Запуск программы, «О программе», появление панели.

B · Прятки

Панель сжимается в тонкую полоску у кромки — так программа выглядит, когда спрятана, — и раскрывается. Значок в трее: спрятана / показана.

C · Модули

В панели по очереди загораются три метки — модули. Загрузка, поиск обновлений, ожидание.

D · Пульс

Панель дважды мигает яркостью. Внимание: напоминание, встреча, ошибка (в красном — как у других программ).

«Меньше движения»: вместо анимации — конечное состояние (панель на месте, без мигания).
