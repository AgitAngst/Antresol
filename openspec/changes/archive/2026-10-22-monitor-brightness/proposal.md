## Why

Яркость внешних мониторов в Windows меняется только кнопками самого монитора. Это первый ★-кандидат
из SPEC.md (аналог — Twinkle Tray); владелец велел идти по кандидатам подряд (22.10.2026).

## What Changes

- Карточка «Яркость»: для каждого внешнего монитора, отвечающего по DDC/CI, — ползунки яркости и
  контраста (колесо мыши — шаг 5 %), чипы входов из строки возможностей монитора.
- Смена входа — только после подтверждения: экран может погаснуть.
- Все запросы к мониторам — в своём потоке; скопившиеся значения ползунка сводятся к последнему.
- Мониторы не отвечают (встроенный экран, DDC/CI выключен) — пояснение.
- Выравнивание яркости между мониторами не входит.
- Версия 0.4.0.

## Capabilities

### New Capabilities
- `monitor-brightness`: яркость, контраст и вход внешних мониторов по DDC/CI.

### Modified Capabilities
- нет.

## Impact

`src/sys/ddc.rs` (новый), `src/sys/monitor.rs` (HMONITOR у монитора), `src/modules/brightness.rs`
(новый), `src/texts.rs`, docs. Новых зависимостей нет (dxva2 — в уже подключённой функции крейта `windows`).
