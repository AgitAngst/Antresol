## Context

Образец вида — макет на холсте «Antresol — новый вид», страница «Идеи ★ — 26.10»: в шапке поле-кнопка 204 × 30
(`raised`, рамка `border_strong`, значок `Search` 14, «Найти действие», справа клавиша «Ctrl K» моноширинным 11 в рамке);
доска «Поиск действий»: в шапке поле 34 высотой до 620 шириной (рамка 1,5 `accent`, значок `Search` цветом
`accent_text`, поле 14,5, справа крестик «Стереть»), правее подсказка 12,5 `weak` «↑↓ — выбрать · Enter — выполнить ·
Esc — назад» и крестик «Закрыть поиск (Esc)». Тело: слева карточка (доля 2,3) — `section_label` «Найдено · N», строки 40:
значок в квадрате 28 (`raised`; выбранная — `badge_fill(accent)` и `accent_text`), название 13,5 с совпадением полужирным
`accent_text`, ниже «где» 12 `weak`; выбранная строка — подложка `raised` и полоска 2 `accent` слева, справа клавиша
«Enter»; справа карточка (доля 1) «Можно так»: чипы-запросы моноширинным и пояснение `weak`. Правила вида —
`docs/ui-guideline.md`, набор anvil-ui.

## Decisions

### 1. Действия

- `Module::actions(&self, t: &Tr, lang) -> Vec<Action>`; `Action { id: String, title: String, place: String, icon:
  Icon, words: String (слова для поиска, оба языка — по `lang`), enabled: bool, reason: Option<String> }`. Выполнение —
  `Command::RunAction(id)` модулю-владельцу (как другие команды); модуль делает то же, что делает щелчок в карточке
  (те же функции, те же уведомления и «Оставить?»).
- Свои действия панели (не модулей): открыть полку «…», «Изменить полки», «Настройки», «Спрятать».
- Список по модулям (что уже есть в карточке): сцены (поставить; стоящая — «Вернуть как было»), «Экран» (избранное и все
  режимы монитора панели — «Экран: 1920 × 1080 · 240 Гц», масштабы, HDR вкл/выкл, «Сделать основным»), «Яркость»
  (25/50/75/100 %, «Ночной свет» вкл/выкл), «Быстрые настройки» (каждая плитка — вкл/выкл по текущему состоянию, планы
  питания, VPN подключить/отключить), «Медиа» (играть/пауза, следующий, предыдущий), «Таймеры» (5, 10, 15 мин,
  «Помидор»), «Инструменты» («Пипетка», «Выделить область»), «Буфер обмена» (закреплённые тексты — «Скопировать «…»»),
  «Лоток» (файлы — «Открыть «…»»), «Кнопки» (свои кнопки), «GitHub» (открыть репозиторий), «Часы» («Добавить пояс»),
  «Bluetooth» («Параметры Bluetooth»). «Звук» — только если модуль сам отдаёт действия (не трогать `sound.rs` — у него
  пустой список по умолчанию).
- Недоступное действие в списке есть, но серое, с причиной во второй строке, Enter не выполняет.

### 2. Поиск (`src/search.rs`, чистые функции)

- Сравнение без регистра, «ё» = «е»; запрос — слова через пробел, каждое должно найтись в названии или словах действия.
- Порядок: совпадение с начала названия → с начала слова → внутри; при равенстве — недавние выше; дальше — порядок полок.
- Пустой запрос — до 7 недавних действий (в памяти, пока работает программа); нет — подсказка «Начните печатать».
- Калькулятор: запрос только из цифр, `+ − * / ( )`, пробелов и `,`/`.` с хотя бы одним действием — свой разбор (не
  `eval`); результат по языку (`7` / `3,5` / `3.5`); строка «2*3,5 = 7», Enter — копировать результат в буфер
  (уведомление «В буфере — вставляйте»). Деление на ноль, переполнение — строки нет.
- Таймер: «<слово> <число>» или «<число> мин» (число 1–999) → «Таймер «чай» на 5 мин» (имя — слово, иначе как сейчас у
  быстрых таймеров); Enter запускает таймер.
- Показано до 7 строк; выбранная — первая; ↑↓ по кругу не ходят.

### 3. Вид и клавиши

- `View::Search`: открыть — щелчок по полю в шапке, Ctrl+K, Ctrl+F; печатная буква или цифра при открытой панели, когда
  фокус не в поле ввода и не идёт захват клавиши, — открыть поиск с этой буквой. Esc в поиске — назад к карточкам
  (второй Esc, как сейчас, прячет панель). Enter — выполнить выбранное и вернуться к карточкам. В правке полок и в
  правке сцены поиск не открывается.
- Шапка в поиске: знак, «Antresol», поле, подсказка, крестик; вкладок, сцен и кнопок нет. Шапка карточек: поле-кнопка
  204 между вкладками и сценами; на узкой панели — только значок `Search` с подсказкой (порядок сворачивания шапки §1).
- «Можно так»: «ночн» — ночной свет, «1080» — режим экрана, «чай 5» — таймер на 5 минут, «2*3,5» — посчитать, «кино» —
  сцена, «тишина» — уведомления (EN: night, 1080, tea 5, 2*3.5, movie, quiet); щелчок — подставить запрос.
