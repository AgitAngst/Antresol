## Context

Образец вида — макет на холсте «Antresol — новый вид», страница «Идеи ★ — 26.10»: в шапке поле-кнопка 204 × 30
(`raised`, рамка `border_strong`, значок `Search` 14, «Найти действие», справа клавиша «Ctrl K» моноширинным 11 в рамке);
доска «Поиск действий»: в шапке поле 34 высотой до 620 шириной (рамка 1,5 `accent`, значок `Search` цветом
`accent_text`, поле 14,5, справа крестик «Стереть»), правее подсказка 12,5 `weak` «↑↓ — выбрать · Enter — выполнить ·
Esc — назад» и крестик «Закрыть поиск (Esc)». Тело: слева карточка (доля 2,3) — `section_label` «Найдено · N», строки 40:
значок в квадрате 28 (`raised`; выбранная — `badge_fill(accent)` и `accent_text`), название 13,5 с совпадением полужирным
`accent_text`, ниже «где» 12 `weak`; выбранная строка — подложка `raised` и полоска 2 `accent` слева, справа клавиша
«Enter»; справа карточка (доля 1) «Можно так»: чипы-запросы моноширинным и пояснение `weak`. Правила вида —
`docs/ui-guideline.md`, набор anvil-ui.

## Decisions

### 1. Действия

- `Module::actions(&self, t: &Tr, lang) -> Vec<Action>`; `Action { id: String, title: String, place: String, icon:
  Icon, words: String (слова для поиска, оба языка — по `lang`), enabled: bool, reason: Option<String> }`. Выполнение —
  `Command::RunAction(id)` модулю-владельцу (как другие команды); модуль делает то же, что делает щелчок в карточке
  (те же функции, те же уведомления и «Оставить?»).
- Свои действия панели (не модулей): открыть полку «…», «Изменить полки», «Настройки», «Спрятать».
- Список по модулям (что уже есть в карточке): сцены (поставить; стоящая — «Вернуть как было»), «Экран» (избранное и все
  режимы монитора панели — «Экран: 1920 × 1080 · 240 Гц», масштабы, HDR вкл/выкл, «Сделать основным»), «Яркость»
  (25/50/75/100 %, «Ночной свет» вкл/выкл), «Быстрые настройки» (каждая плитка — вкл/выкл по текущему состоянию, планы
  питания, VPN подключить/отключить), «Медиа» (играть/пауза, следующий, предыдущий), «Таймеры» (5, 10, 15 мин,
  «Помидор»), «Инструменты» («Пипетка», «Выделить область»), «Буфер обмена» (закреплённые тексты — «Скопировать «…»»),
  «Лоток» (файлы — «Открыть «…»»), «Кнопки» (свои кнопки), «GitHub» (открыть репозиторий), «Часы» («Добавить пояс»),
  «Bluetooth» («Параметры Bluetooth»). «Звук» — только если модуль сам отдаёт действия (не трогать `sound.rs` — у него
  пустой список по умолчанию).
- Недоступное действие в списке есть, но серое, с причиной во второй строке, Enter не выполняет.

### 2. Поиск (`src/search.rs`, чистые функции)

- Сравнение без регистра, «ё» = «е»; запрос — слова через пробел, каждое должно найтись в названии или словах действия.
- Порядок: совпадение с начала названия → с начала слова → внутри; при равенстве — недавние выше; дальше — порядок полок.
- Пустой запрос — до 7 недавних действий (в памяти, пока работает программа); нет — подсказка «Начните печатать».
- Калькулятор: запрос только из цифр, `+ − * / ( )`, пробелов и `,`/`.` с хотя бы одним действием — свой разбор (не
  `eval`); результат по языку (`7` / `3,5` / `3.5`); строка «2*3,5 = 7», Enter — копировать результат в буфер
  (уведомление «В буфере — вставляйте»). Деление на ноль, переполнение — строки нет.
- Таймер: «<слово> <число>» или «<число> мин» (число 1–999) → «Таймер «чай» на 5 мин» (имя — слово, иначе как сейчас у
  быстрых таймеров); Enter запускает таймер.
- Показано до 7 строк; выбранная — первая; ↑↓ по кругу не ходят.

### 3. Вид и клавиши

- `View::Search`: открыть — щелчок по полю в шапке, Ctrl+K, Ctrl+F; печатная буква или цифра при открытой панели, когда
  фокус не в поле ввода и не идёт захват клавиши, — открыть поиск с этой буквой. Esc в поиске — назад к карточкам
  (второй Esc, как сейчас, прячет панель). Enter — выполнить выбранное и вернуться к карточкам. В правке полок и в
  правке сцены поиск не открывается.
- Шапка в поиске: знак, «Antresol», поле, подсказка, крестик; вкладок, сцен и кнопок нет. Шапка карточек: поле-кнопка
  204 между вкладками и сценами; на узкой панели — только значок `Search` с подсказкой (порядок сворачивания шапки §1).
- «Можно так»: «ночн» — ночной свет, «1080» — режим экрана, «чай 5» — таймер на 5 минут, «2*3,5» — посчитать, «кино» —
  сцена, «тишина» — уведомления (EN: night, 1080, tea 5, 2*3.5, movie, quiet); щелчок — подставить запрос.

### 4. Тексты (RU / EN), одним блоком

«Найти действие» / "Find an action", «Или просто начните печатать, пока панель открыта» / "Or just start typing while the
panel is open", «Стереть» / "Clear", «Закрыть поиск (Esc)» / "Close search (Esc)", «↑↓ — выбрать · Enter — выполнить ·
Esc — назад» / "↑↓ select · Enter run · Esc back", «Найдено» / "Results", «Недавние» / "Recent", «Начните печатать» /
"Start typing", «Можно так» / "Try", «Ничего не нашлось — попробуйте другое слово» / "Nothing found — try another word",
«Посчитать · Enter — скопировать результат» / "Calculate · Enter copies the result", «Таймер «{}» на {} мин» / "Timer
“{}” for {} min", «Открыть полку «{}»» / "Open the “{}” shelf" и названия действий модулей — из существующих строк, где
есть (подписи плиток, кнопок, «Вкл»/«Выкл» → «включить»/«выключить» — новые строки).

## Уточнено при реализации

- **Сигнатура и `Action`.** `Module::actions(&self, t, lang, settings)` — к строкам и языку добавлены настройки: закреплённые
  тексты, лоток, репозитории и избранное лежат в них. У `Action` лишний признак `needs_free_pointer` («нужна мышь вне
  панели»): пока мышь над самой панелью, такое действие серое — «Наведите мышь на цвет вне панели». Код — `src/app/search_ui.rs`
  (дочерний модуль `app`: ему видны поля `App`), чистые функции — `src/search.rs`.
- **«Пипетка».** В карточке это круг, который тянут мышью, — щелчка у неё нет, поэтому из поиска она берёт цвет под мышью,
  будто круг отпустили над этим местом (`Tools::take`, общий с отпусканием круга путь): код цвета в буфер, «#2a5fd0 в буфере».
  `monitor::pixel_at` в выдуманном мире (демо и тесты) отдаёт выдуманный цвет. «Выделить область» — та же кнопка, что в карточке;
  пока ждём выделения, серое («Выделите область на экране…»).
- **Место и слова.** Место — «карточка · полка» (название полки — как на вкладке; у сцены — «Сцены · клавиша»; у своих
  действий панели — «Antresol»). К словам действия добавлено имя карточки («яркость» находит «Ночной свет»), имя полки не
  добавлено: иначе «экран» нашёл бы всё на полке «Экран и звук». Карточка, которой нет ни на одной полке, действий не даёт.
- **Таймер из запроса** встаёт следом за лучшим совпадением, а не первым, если что-то нашлось: «яркость 50» — это «Яркость:
  50 %», а не таймер «яркость» на 50 минут; ничего не нашлось («чай 5») — таймер первый. Калькулятор — всегда первым. У таймера
  появилось имя (`timers:new:<минуты>:<имя>`; в списке карточки, в подсказке к метке вкладки — на самой метке только время —
  и в уведомлении «Таймер «чай» дошёл»); «<число> мин» — без имени, как у быстрых таймеров. Таймер из запроса в недавние не
  попадает. Карточки «Таймеры» нет ни на одной полке — строки таймера тоже нет (как у остальных её действий).
- **Шапка.** Значок поиска есть всегда; что ещё показать, решает `header_plan::plan` по ширине панели и размерам частей — один
  порядок на все ширины: подписи «Сцена» и «Монитор», слово «Antresol», поле 204 → значок, подписи вкладок, монитор, сцены.
  Решение не зависит от места, что осталось от правой части в прошлом кадре, поэтому при сужении ничего не мигает и не
  возвращается (в первой версии слово «Antresol» и подпись «Сцена» переключались по семь раз). В поиске слово стоит, пока с
  ним помещается подсказка, а подсказка — пока помещается без него.
- **Когда открывается.** Только поверх карточек: не в правке полок и сцены, в настройках и «Своём цвете», не пока вводят
  текст (поле «owner/repo», поиск пояса у «Часов», имя полки), ждут сочетание или фокус в поле ввода — это касается и Ctrl+K с
  Ctrl+F. Напечатанное за кадр (быстрый набор приносит несколько букв) целиком становится началом запроса и забирается у
  кадра: поле не вставит его второй раз. Висит «Оставить этот режим?» — Ctrl+K открывает, действия «Экрана» серые («Сначала
  ответьте…»), а печать поиск не открывает: вопрос не должен уйти под него. Пока вид открыт, панель сама не прячется (ни
  уход мыши, ни потеря фокуса): «Пипетке» из поиска нужна мышь вне панели; закрывают Esc, крестик, клавиша показа панели или
  выполненная строка.
- **Номера действий и «Недавние».** Номер действия не зависит от места в списке: `tray:open:<путь>`,
  `clipboard:copy:<отпечаток текста>`, `buttons:run:<отпечаток имени, программы и аргументов>`, `shelf:<имя полки>`,
  `scene:<номер сцены>`. «Недавние» держатся за эти номера: пропавшее не показывается, остальное не сползает на соседей.
- **Калькулятор.** Запятая в числе — по языку: по-русски десятичная, по-английски разделитель тысяч («1,000*2» — 2000; «1,5» —
  не число). Ответ — до 12 значащих цифр без шума двоичной точности; слагаемые, что взаимно уничтожились (`0,1 + 0,2 − 0,3`),
  дают 0; меньше 1е-6 — с порядком.
- **Клавиатура.** Панель, что выехала у края, раньше забирала её у программы пользователя, и набранное там («буду через
  10» + Enter) становилось запросом, а Enter заводил таймер. Теперь выдвинутая мышью панель клавиатуру не забирает (окно
  неактивно, как полоска: `WS_EX_NOACTIVATE`, без `Focus`), пока в ней не нажмут мышью: первое нажатие делает окно активным
  и работает как обычный щелчок. Вызванная клавишей показа или клавишей сцены берёт её сразу. Печать открывает поиск только у
  панели с клавиатурой (`panel::Edge::keyboard`). Выезд по таймеру при выключенной полоске берёт её, как раньше.
- **Данные.** Пока открыт вид поиска, `refresh_set` опрашивает все карточки, что стоят на полках (действия строятся по
  прочитанному). Стрелки забирает шапка до поля, Enter — по `lost_focus` поля, выполняет вид по готовому списку; прокрутка списка
  следует за выбранной строкой.
- **Тексты** (одним блоком в `texts.rs`): поля `search_*` (поле, подсказки, «Найдено», «Недавние», «Начните печатать», «Можно
  так», «Ничего не нашлось…», «Посчитать · Enter — скопировать результат»; «Наведите мышь на цвет вне панели», «Спрятать
  панель», «вернуть как было», «цвет под мышью», «играть», «пауза», «следующий трек», «предыдущий трек»), `turn_on` /
  `turn_off` («включить» / «выключить»), `scale_word` («Масштаб»), `timer_named_done` (шаблон с `{}`), `tips` (шесть примеров
  запросов) и функции `search_timer`, `search_open_shelf`, `search_open`, `search_copy`. Причины серых строк — готовые тексты
  программы: «Сначала ответьте на «Оставить этот режим?»», «Windows сейчас не даёт включить HDR на этом мониторе», «Опрашиваю
  мониторы…», «Мониторы не отвечают по DDC/CI…», «Недоступно», «Windows не отдала значение», «Нет радио Wi‑Fi», «Ничего не
  играет.», «нет файла», «Выделите область на экране…».
- **Тесты.** Без окна и без Windows: `search` — чистые функции; каждый модуль — список действий и выполнение на выдуманном мире
  (запуск «Ножниц» — `sys::launch`, кнопки плеера — `media::act`: оба за заслоном `sys::blocked`; действия «Медиа» проверены и
  на подставленном канале потока); `app::tests` — `Rig` жмёт Ctrl+K, печатает, листает, Enter и щелчок выполняют.
