# Значок Антресоли

Монитор с яркой панелью сверху на светлой плитке (одна для обеих тем). Выбран владельцем 28.10.2026.

| Файл | Что это |
|---|---|
| `antresol.svg` | Полный знак, viewBox 1024; источник для 64 px и крупнее |
| `antresol-small.svg` | Упрощённый для 16–48 px: панель выше (130), подставка толще |
| `antresol-{16,24,32,48}.png` | Из `-small.svg` |
| `antresol-{64,128,256,512}.png` | Из полного SVG |
| `antresol.ico` | Кадры PNG 16, 24, 32, 48, 64, 128, 256 (значок exe) |

- Плитка: градиент `#F6F8EF → #DCE5CB`; знак `#5E9A1A`; тело монитора — прозрачность 0,5, яркая панель — 1, подставка — 0,55.
- Центровка («Середина»): знак сдвинут вниз на 28 (полный) и 23 (мелкий) — в группе `glyph` каждого SVG.
- Пересборка: `scripts/render-icon.ps1` (нужен `scoop install resvg`); второй запуск без правок SVG даёт те же байты.
- Знак в интерфейсе (`src/mark.rs`) рисуется кодом по числам мелкого SVG.
