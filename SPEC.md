# Antresol — замысел и этапы

Панель у верхнего края монитора: прячется за край, выезжает, когда мышь касается края или по
горячей клавише. Размер меняется мышью, функции — модули, движение по набору Anvil. Запросы
владельца 22.10.2026: изменяемый размер, прячется, можно добавлять новые функции и быстрые
настройки, красивые анимации; первые функции — разрешение и масштаб экрана, звук.

## Этап 0.1 — первая версия (сделан 22.10.2026)

- Окно-панель у края, автоскрытие, выезд по краю и по клавише, показ при запуске, закрепление.
- Размер тянется за нижний край, бока и нижние углы; запоминается.
- Модуль «Экран»: разрешение, частота, масштаб; «Оставить?» с откатом через 15 с.
- Модуль «Звук»: громкость, без звука, устройство вывода.
- Модуль «Кнопки»: свои кнопки из `buttons.txt`.
- Настройки: монитор, автозапуск, «не выезжать над играми», задержки, тема, язык.

## Этап 0.2 — избранное и частоты (сделан 22.10.2026, запрос владельца)

- До трёх любимых разрешений на монитор: звёздочка в списке, чипы сверху, один щелчок.
- Частота запоминается для каждого разрешения и ставится при переходе на него.
- Частоты и масштабы — чипами с переносом (в 0.1 полоса обрезалась).

## Этап 0.3 — профили экрана с горячими клавишами (сделан 22.10.2026, запрос владельца)

Изменение OpenSpec `display-profiles` (архив `2026-10-22-display-profiles`).
- Профиль: имя, клавиша, режим и масштаб каждого монитора; сохраняется из текущего, ставится щелчком.
- Клавиша профиля назначается в настройках захватом сочетания, работает при спрятанной панели.
- Применение — с «Оставить этот режим?» и откатом всех изменённых мониторов через 15 с.
- Не вошло: расположение мониторов в профиле, клавиши на избранное, выбор клавиши показа панели.

## 0.3.1 — звук убран (22.10.2026, решение владельца)

Владелец: «Исключи всё что связано со звуком. Потом сделаем интеграцию Kamerton.» Карточка «Звук»
(громкость, «без звука», устройство вывода) и её системная часть удалены; громкость по программам и
микрофон из планов сняты. Звук в панели появится через интеграцию с
[Kamerton](https://github.com/AgitAngst/Kamerton) — отдельный этап после согласования с владельцем.

## Этап 0.4 — яркость мониторов (сделан 22.10.2026)

Изменение OpenSpec `monitor-brightness` (архив `2026-10-22-monitor-brightness`). Карточка «Яркость»: яркость, контраст, вход внешних мониторов
по DDC/CI, смена входа с подтверждением. Не вошло: выравнивание яркости между мониторами, встроенный
экран ноутбука (WMI).

## Этап 0.5 — медиа (сделан 22.10.2026)

Изменение OpenSpec `media` (архив `2026-10-22-media`). Карточка «Медиа»: обложка, название, исполнитель, программа; «Назад»,
«Пауза», «Вперёд». Ряд карточек листается вбок на узкой панели.

## Этап 0.6 — сама панель (сделан 22.10.2026)

Изменение OpenSpec `panel-itself` (архив `2026-10-22-panel-itself`). Полоска у края, «Не выезжать над программами», монитор «Все», своя
клавиша показа панели; для разработки — `ANTRESOL_SHOT`. Не вошло: свои настройки у каждого монитора.

## Этап 0.7 — ресурсы (сделан 22.10.2026)

Изменение OpenSpec `resources` (архив `2026-10-22-resources`). Карточка «Ресурсы»: процессор с графиком, видеокарта, память, сеть,
батарея, диски. Не вошло: температура (нужны права администратора или драйвер).

## Этап 0.8 — буфер обмена и лоток (сделан 22.10.2026)

Изменение OpenSpec `clipboard-tray` (архив `2026-10-22-clipboard-tray`). История буфера (20 текстов, только в памяти), лоток брошенных
файлов. Не вошло: перетаскивание из лотка наружу, картинки в истории буфера.

## Этап 0.9 — правка карточек и Bluetooth (сделан 22.10.2026)

Изменение OpenSpec `edit-bluetooth` (архив `2026-10-22-edit-bluetooth`). «Карточки панели» в настройках (вкл/выкл, порядок), карточка
«Bluetooth» (подключено, заряд). Не вошло: перетаскивание карточек мышью, «только значки», подключение
устройств из панели.

## Этап 1.0 — таймеры (сделан 22.10.2026)

Изменение OpenSpec `timers` (архив `2026-10-22-timers`). Быстрые таймеры и «помидор»; дошёл — уведомление и выезд панели. Не вошло:
напоминания по времени суток, календарь (без учётной записи Windows событий не отдаёт).

## Этап 1.1 — состояние GitHub (сделан 22.10.2026)

Изменение OpenSpec `github` (архив `2026-10-22-github`). Карточка «GitHub»: последний прогон CI и открытые пулл-реквесты, только
чтение. Не вошло: список PR по названиям, уведомления о смене состояния.

## Этап 1.2 — новый вид (сделан 22.10.2026, запрос владельца)

Изменение OpenSpec `new-look`. По макету на холсте, одобренному владельцем: цвет — лайм по умолчанию, пять
готовых и «Свой цвет…» с подстройкой под тему; профили экрана в шапке; заголовки карточек со значком; «Экран»
с крупным текущим режимом и избранным строками; «Ещё N ›» у не влезшего ряда; полоска наполняется за
задержку выезда; «Медиа на спрятанной полоске»; плашка таймера у края вместо выезда панели; настройки
строками, порядок карточек перетаскиванием. Не вошло: ход трека на полоске (Windows не отдаёт позицию).

## Этап 1.3 — звук через Kamerton (сделан 22.10.2026, запрос владельца)

Изменение OpenSpec `kamerton-sound`. Карточка «Звук»: устройство вывода по умолчанию и программы — громкость
и «без звука», «Микшер Kamerton». Звук делает Kamerton (0.2.1, канал `kamerton-ipc`), панель только просит.

## Дальше — идеи из мозгового штурма (не согласованы, порядок решит владелец)

| Раздел | Что |
|---|---|
| Экран | яркость внешних мониторов (DDC/CI), ночной свет, основной монитор, профили «работа/игра» |
| Система | не давать уснуть, план питания, тема Windows, «не беспокоить», Bluetooth-устройства, Wi‑Fi и VPN |
| Окна | раскладки по зонам, «поверх всех», перенос на другой монитор |
| Буфер и снимки | история буфера, заготовки текста, пипетка, снимок области с распознаванием |
| Состояние | ЦП, видеокарта, память, температура, место на E:, сеть, CI на GitHub |
| Медиа и время | плеер, таймер, «помидор», часы других поясов |
| Сама панель | значок программы, порядок и включение модулей в настройках, выбор горячей клавиши |
