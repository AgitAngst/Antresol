# Antresol

Панель быстрого доступа у верхнего края монитора для Windows: прячется за край, выезжает по
касанию края мышью или по горячей клавише. Сцены (экран и системные настройки одним щелчком или клавишей, второй щелчок возвращает как было), экран
(разрешение, частота, масштаб, HDR монитора, избранное), яркость, контраст и вход внешних мониторов (DDC/CI), ночной свет, звук (через
[Kamerton](https://github.com/AgitAngst/Kamerton): громкость устройства и программ), медиа (что играет, «назад»,
«пауза», «вперёд»), быстрые настройки (не спать, тёмная тема, «Тишина», Wi‑Fi, план питания, VPN), ресурсы (процессор,
видеокарта, память, сеть, температура, батарея, диски), буфер обмена (текст, ссылки, цвета, картинки, «Исправить раскладку») с закреплёнными текстами, лоток файлов,
инструменты (пипетка, текст с экрана), часы других поясов, Bluetooth-устройства (наушники, гарнитуры и колонки подключаются и отключаются щелчком), таймеры и «помидор», встречи из календаря
Google или Outlook по секретной ссылке .ics («Подключиться» одним щелчком), состояние GitHub (CI и пулл-реквесты), свои кнопки. Любое действие панели — с клавиатуры: Ctrl+K или просто начать печатать, пока панель
открыта («ночн» — ночной свет, «1080» — режим экрана, «кино» — сцена, «чай 5» — таймер, «2*3,5» — посчитать). Карточки разложены по четырём полкам — вкладкам в шапке («Экран и звук», «Система»,
«День», «Под рукой»); какие карточки, где и в каком порядке — правка полок на самой панели (карандаш в шапке).

Пока панель спрятана, события приходят **живыми плашками** у края — без выезда панели и без кражи клавиатуры: наушники подключились или
батарея села, вставлена флешка («Извлечь» безопасно), упала сборка на GitHub, скачан файл (его можно потянуть с плашки в чат или папку),
таймер дошёл, через две минуты начнётся встреча («Подключиться»). Каждый вид событий (кроме таймера) можно выключить в настройках.
