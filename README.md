# Antresol

Панель быстрого доступа у верхнего края монитора для Windows: прячется за край, выезжает по
касанию края мышью или по горячей клавише. Экран (разрешение, частота, масштаб, избранное,
профили с горячими клавишами), яркость, контраст и вход внешних мониторов
(DDC/CI), медиа (что играет, «назад», «пауза», «вперёд»), ресурсы (процессор, видеокарта, память, сеть,
батарея, диски), история буфера обмена, лоток файлов, Bluetooth-устройства, таймеры и «помидор», свои кнопки; какие карточки видны и
в каком порядке — в настройках. Звука в панели нет: он будет из
[Kamerton](https://github.com/AgitAngst/Kamerton).

Документация — [docs/README.md](docs/README.md).
