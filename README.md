# Antresol

Панель быстрого доступа у верхнего края монитора для Windows: прячется за край, выезжает по
касанию края мышью или по горячей клавише. Сцены (экран и системные настройки одним щелчком или клавишей, второй щелчок возвращает как было), экран
(разрешение, частота, масштаб, HDR монитора, избранное), яркость, контраст и вход внешних мониторов (DDC/CI), ночной свет, звук (через
[Kamerton](https://github.com/AgitAngst/Kamerton): громкость устройства и программ), медиа (что играет, «назад»,
«пауза», «вперёд»), быстрые настройки (не спать, тёмная тема, «Тишина», Wi‑Fi, план питания, VPN), ресурсы (процессор,
видеокарта, память, сеть, температура, батарея, диски), буфер обмена с закреплёнными текстами, лоток файлов,
инструменты (пипетка, текст с экрана), часы других поясов, Bluetooth-устройства, таймеры и «помидор», состояние GitHub
(CI и пулл-реквесты), свои кнопки. Любое действие панели — с клавиатуры: Ctrl+K или просто начать печатать, пока панель
открыта («ночн» — ночной свет, «1080» — режим экрана, «кино» — сцена, «чай 5» — таймер, «2*3,5» — посчитать). Карточки разложены по трём полкам — вкладкам в шапке («Экран и звук», «Система»,
«Под рукой»); какие карточки, где и в каком порядке — правка полок на самой панели (карандаш в шапке).
