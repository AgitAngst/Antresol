# Antresol — правила для сессий и агентов

Что это: панель быстрого доступа у верхнего края монитора для Windows (Rust, egui, набор Anvil).
Состояние и долги владельца — [HANDOFF.md](HANDOFF.md); замысел и этапы — [SPEC.md](SPEC.md);
документация того, что есть сейчас, — [docs/README.md](docs/README.md); работа идёт через OpenSpec
(`openspec/changes/<имя>`). Весь текст пользователю — по-русски; тексты в интерфейсе — RU/EN,
светлая и тёмная тема.

## Интерфейс

- Любая работа с видом — по [docs/ui-guideline.md](docs/ui-guideline.md); новое правило — туда же в том же шаге.
- Цвета, шрифты, кнопки — только из `anvil-ui` (тег `kit-v*` в `Cargo.toml`); свои hex — только акценты в
  `src/look.rs` (лайм и ещё четыре, решение владельца 22.10.2026).

## Общие скрипты

- Готовые помощники — `E:\dev_personal\tools\` (оглавление `README.md` там): `patch.py`, `checks.py`,
  `bump_version.py` и др. Скрипты самого проекта — в `scripts/`.

## Диски

- Только **E:** — репозиторий, worktrees, `target`, логи. Общая папка — `E:\dev_personal\antresol-scratch`
  (отчёты агентов — `reports\`, сборка судей — `target-judge\`, снимки и журналы проверок). D: запрещён.

## Сборка и проверка (на ПК; CI — только по слову владельца)

- По ходу — `cargo check -j 4`, вывод в файл.
- Перед сдачей один раз: `python E:/dev_personal/tools/checks.py --repo . -j 4 fmt test clippy`
  (программа только под Windows — шаг `zig` не нужен).
- Результат — по коду выхода; вывод в файл, в разговор хвост.
- Живая проверка окна: запустить `target\debug\antresol.exe`, снять экран; **курсор пользователя не двигать**
  — он может работать за ПК. `ANTRESOL_TRACE=1` печатает, куда и какого размера ставится окно.
- Живые проверки не меняют настройки пользователя: экран, яркость, автозапуск — только по команде владельца;
  окно для проверки — только с `ANTRESOL_DEMO=1`.

## Работа агентов

- Исполнитель — свой worktree, коммиты по-английски в своей ветке, не пушит; называет ветку и хэш.
- Судья и сверщик документации — без worktree, читают `main`, собирают в `target-judge`.
- Отчёт — до ~25 строк, подробности в `antresol-scratch\reports\<имя>.md`.
- Версию агент не меняет, если задача этого прямо не требует.

## Открытый репозиторий

- https://github.com/AgitAngst/Antresol — **открытый**. В коммиты, снимки и документы — только выдуманные
  данные: снимки — в демо-режиме (`ANTRESOL_DEMO=1 ANTRESOL_PIN=1`, настройки `antresol-scratch\demo`;
  **правило демо: клавиш профилей нет, монитор несуществующий (`\\.\DISPLAY9`), в Windows ничего не пишется**; каждый
  снимок открыть и посмотреть: на нём только панель, без экрана за ней и без настоящих режимов монитора, английские —
  без русских демо-текстов; в `docs/img` — через `scripts\squeeze-png.ps1`), без настоящих имён
  устройств, путей и чужих программ. Приватные ветки, закрытые репозитории и проекты владельца не упоминать
  вовсе — ни в файлах, ни в сообщениях коммитов.
